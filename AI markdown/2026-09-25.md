## 迭代 6：修复「部分卡片课程名消失」的 CSS bug（用户报障：Chrome + Safari）

**症状**：macOS 上 Chrome / Safari 打开页面，部分卡片只剩标签与学分，**课程名整块不见了**。

**排查过程（可复用的诊断套路）**：
1. `--dump-dom` 导出真实渲染 DOM → 74 张卡片 `c-name` 全部有文本、无空值 → 排除数据/HTML 转义问题。
2. 注入诊断脚本（`setTimeout` 后测量 + 把 JSON 写进 `<pre id="diag">`，再 `--dump-dom` 回收）在多个视口宽度下测量盒模型。
   发现 `computer system基础…` 等 7 张卡 `c-name` 的 `getBoundingClientRect().height === 0`，而 `scrollHeight` 为 18/35。

**根因**：
- `.c-name` 用了 `display:-webkit-box; -webkit-line-clamp:2; overflow:hidden`。
- 这些卡片的 `课程属性` 标签很长（`专业群平台课（专业基础课）` / `专业综合技能（含实践）课`），
  在 160px 宽的卡里把 `.c-meta` 挤成两行 → 卡片内容需要 ~117px，而网格行高只有 `min-height` 的 96px。
- 高度不足时 flex 收缩：`.c-name` 因 `overflow:hidden` 可被压到 **0 高度**，`.c-meta`/`.c-foot` 有最小内容高度压不动 → **课程名消失**。
- 触发条件正是「名字较长 + 课程属性标签较长」的那 7~10 张卡，所以表现为「部分卡片名字缺失」。

**修复**：
- `.c-name` 改为 `display:block; overflow:visible; flex:0 0 auto; word-break:break-word; overflow-wrap:anywhere;`
  —— 彻底去掉 `-webkit-line-clamp` 这类脆弱裁剪（它的内在高度贡献不可靠），名字完整换行显示、永不被压缩。
- `.c-meta`、`.c-foot` 加 `flex:0 0 auto`，杜绝任何子元素被压扁到不可见。
- 复测 1440/1280/1024/900/760/640 六个宽度：`invisible=0`、`clipped=0`，74 张卡名字高度只有 17.5 或 35.1（1~2 行）。

**教训（写进长期备忘）**：卡片类布局不要用 `-webkit-line-clamp` + `overflow:hidden` 做截断；
要么让文本完整换行，要么用固定高度且配合 `title` 提示。flex 子项一律显式声明 `flex-shrink`，避免被压成 0。

## 迭代 7：修复「长名字把学分挤出卡片」（用户报障）

**症状**：`LSEPIs法律、社会、道德与专业（全英文）` 这类长名字卡片，底部「学分」行被挤到卡片外。

**排查**：全站扫描「元素矩形超出父元素内边距盒」→ 命中 `div.c-foot` 超出 `div.card` 底部 14.3px（上一轮的 flex-shrink:0 修复把"名字消失"变成了"内容外溢"）。

**真正的根因（A/B 实验定位）**：`.zone-body` 同时是 **`flex:1` + `max-height:46vh` + `overflow-y:auto` 的"有确定高度的滚动容器"** 时，
Blink 会把 `grid-auto-rows:auto` 的行高按 **min-content** 计算（= 卡片 `min-height:96px`），
于是内容需要 110px 的卡片被塞进 96px 的行里，底部内容溢出行外。

| 变体 | 卡片高度 | 学分溢出 |
|---|---|---|
| 基线 | 96/110 混杂 | 52 张 |
| **A `grid-auto-rows:max-content`** | 全部 110 | **0** ✅ 采用 |
| B `align-items:start` | 全部 110 | 0 |
| C 去掉卡片 `min-height` | 20/50/110 崩坏 | 52 ✗ |
| D 去掉框 `max-height` | 全部 110 | 0 |

**最终修复**：
1. `.zone-body` / `.pool-body` 显式声明 `grid-auto-rows:max-content`（行高按内容算，不受容器确定高度影响）。
2. `.c-name` 字号 13px→12px，并给 **固定两行高度 `height:2.8em`**：让字高贡献完全确定，且实测 6 个宽度下
   没有任何课程名需要第三行（0 截断、0 溢出）。
3. `.c-meta` 改 `flex-wrap:nowrap` + `.t-attr` 省略号，保证标签行永远单行；`.c-foot` 内 `c-credit` 固定、`c-term/c-lock` 可省略。
4. 卡片 `min-width:0`，避免 nowrap 内容把网格列撑宽。

**复检（1440/1200/1024/900/780/640）**：卡片高度全部 110、名字不可见 0、名字两行放不下 0、
学分溢出卡片 0、页面溢出元素 0。
