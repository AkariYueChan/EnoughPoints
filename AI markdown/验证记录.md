## 前端五项修正（2026-09-26 追加）

用户在前端测试时报了五个问题，全部只改 `index.html`，后端没有改动。真实 Chromium 逐项实测：

1. **选课表排序**：导入的 Excel 按课程编号排序，必修/选修是交错的（专业课原始顺序为「必必选选选必必必必必必选…」），导致选课表里选修夹在必修之间。修复：`expandByTerm` 改为先按学期、再按「必修 0 / 选修 1」排序，同类型保持原表顺序。实测 6 个学期格内必修全部排在选修之前（`bad: []`），类别框里的卡片同样遵循。
2. **生成选课表的校验**：原来把差额算成负数（如「还差 -54 分」），也没有分类说明。修复：`openWarnModal` 改为分列「公共基础课：已修 49 / 58 分，还差 9 分」「专业课：已修 74 / 89 分，还差 15 分」，差额一律取 0 以上；进入选课表收敛为唯一入口 `tryOpenSchedule`，只要任一类别未达标就弹不足提示、打不开选课表（含「选修达标」提示框里的生成按钮）。
3. **公共基础课框加重置按钮**：新增 `btn-reset-public-elec`，`clearElectives(cat)` 按类别框限定作用范围。实测（含公共选修的合成数据）：点公共框重置只退回公共基础课的选修，专业课的选修不受影响；反之亦然。
4. **公共基础课加进度条**：照专业课的样式在公共框加两条——必修 X/Y 门、选修 Z 分。没达标红色、达标绿色（全页面小进度条统一为红/绿，原来是琥珀色）。实测：公共必修 26/26 门绿色满条；没有公共选修时选修条显示空条、边框绿色，不再出现「0 分却满绿条」的误读。
5. **去掉顶部「了解详情」**：删除按钮与 `setupDetail`/`DETAIL_URLS`，页头只剩 GitHub 与「↺ 重新导入」。

回归：后端 21 项测试仍全部通过；`node --check` 通过；Node DOM 外壳（带事件分发）+ 真实 Chromium 双重验证上述五项全部生效。

## 前端两处微调（2026-09-26 追加）

只改 `index.html`，后端没有改动：

1. **公共基础课框的「必修学分」改为「总学分」**：只改描述文案，逻辑不变（`cred-public` 仍是该类已修学分合计）。
2. **专业课框去掉「需≥15」，「还需再选多少分」改为按后端注入的数据计算**：删除选修条上的 `需≥15` 标签；`msg-major` / `foot-major` / `bottom-hint` / 不足弹窗里的「还需再选／还需选修 X 分」统一改为 `max(0, 专业课目标 − 已修学分)`，不再依赖写死的选修下限，目标改了自动跟着变。实测（总学分 130、公共 49 → 专业课目标 81）：初始提示「还需再选 7 学分选修课」（81 − 74），选满后「学分已修满（超修 8 分）」——证明数字由注入数据算出，而非写死的 15。

说明：选修条进度与「选修达标」弹窗仍用后端的选修下限（`elecNeed`，示例数据为 15），与学分目标是两个口径；当总学分 / 公共 / 必修 / 选修四者填得不自洽时（如总 130 小于 公共49+必修74+选修15），两者可能显示不同，属数据配置问题，页面口径不变。回归：后端 21 项测试仍全部通过，Node DOM 外壳 + 真实 Chromium 双重验证。

## 公共基础课选修相关三处修正（2026-09-26 追加）

只改 `index.html`，后端没有改动：

1. **公共基础课「必修 X/Y 门」分母算错**：分母原来取全部公共课门数（`GOAL.public.courseCount`，含选修），公共选修被算进了必修的分母。改为公共基础课的**必修门数**（从注入课程里数 `cat='public' 且 type='必修'`）。实测（含 1 门公共必修 + 2 门公共选修的数据）：由「1/3 门」改为「1/1 门」并绿色满条。
2. **公共基础课选修没有专属卡片颜色**：原来公共选修和公共必修同色（默认蓝边）。新增青绿色（`--pub-elec:#0d9488`）：卡片 `c-public-elec`、选课表 chip `s-public-elec`，图例在「公共必修」后加「公共选修」。实测公共选修卡片左边框为 `rgb(13,148,136)`，选课表四种颜色齐全（公共必修蓝 / 公共选修青绿 / 专业必修橙 / 专业选修紫）。
3. **公共基础课不足但选修够时误弹「已达标」**：原来选修学分一到下限就弹庆祝框，不管公共基础课够不够。修复：触发弹窗时先判断公共基础课是否达标——达标才弹庆祝框，不足则弹出「学分还没修够」提示（明确写出「公共基础课：已修 X / 目标，还差 N 分」）。实测公共目标 58、实际 49 时，选修选满 15 分弹出的是不足提示而非庆祝框，选课表打不开；公共达标后才恢复庆祝框。

回归：后端 21 项测试仍全部通过，规划页脚本语法检查通过，Node DOM 外壳 + 真实 Chromium 双重验证。
