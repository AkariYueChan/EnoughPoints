# EnoughPoints

用 AI 制作的单页 HTML 选课课表生成器。

**适用范围：仅限广州职业技术大学 2026 级物联网应用技术（中外合办）专业。**

## Project Overview

EnoughPoints is a single-page HTML schedule generator.

This is a vibecoding project made by **Akari_Zeng**.

The schedule generator is only for the Year 2026 IOT (Chinese-Foreign COOP) class at “GPU University” [GZPYP].

## 实现的功能

- 像玩游戏一样，通过点击或拖拽卡片规划选课。
- 自动计算学分，帮助确认是否修够所需学分。

**注意：本工具不帮忙抢课。**

## 存在的问题

1. 目前只写了中文版网页，英文版不写，谁有空去翻译奇怪的选课。
2. 暂未适配黑暗模式，因为前途已经很黑暗了。
3. 公共基础课必修 58 学分，但是另外 9 学分不知道被谁吃了。
4. 暂时没有适配挂科后的课表排列问题。
5. 暂时没有解决大专毕业后企业只招本科学历起步的问题。
